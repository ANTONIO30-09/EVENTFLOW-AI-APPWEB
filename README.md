## 🎯 Sobre el Proyecto
**EventFlow AI Admin** es la interfaz web para organizadores de eventos. Permite administrar eventos, invitados, inventario y distribución con IA, conectándose al mismo backend de Firebase (Firestore + Auth) que la app móvil de staff de campo.
